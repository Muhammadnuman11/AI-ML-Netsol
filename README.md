# AI/ML Training at NETSOL Technologies Pakistan

This repository documents my learning journey through the AI/ML training program at NETSOL Technologies Pakistan. It contains practical exercises, Python scripts, notes, and project work covering the fundamentals of programming, data structures, machine learning, and data analysis.

The goal is to build strong hands-on experience in artificial intelligence and machine learning while learning in public and sharing continuous progress.

## Overview

- Duration: 3 Months
- Learning Mode: Practical + Theory
- Focus Areas: Python, Data Structures, OOP, NumPy, Pandas, Machine Learning, Data Visualization, and AI concepts
- Purpose: Strengthen foundational skills and prepare for real-world AI/ML development

## Repository Structure

This repository is organized by topic and learning module:

- `Python lec 01/` — introductory Python practice and basic coding exercises
- `Basic Python 04 - 05/` — core Python concepts including conditionals, loops, and logic-building programs
- `Data Structures in python 03/` — lists, tuples, sets, dictionaries, stacks, queues, linked lists, trees, and graphs
- `Linux lec 02/` — Linux fundamentals, file operations, commands, shell usage, and system basics
- `OOP in python 06 - 07/` — object-oriented programming concepts such as abstraction, encapsulation, inheritance, and polymorphism
- `NumPy and Pandas/` — numerical computing and data manipulation with NumPy and Pandas
- `Pandas and Seaborn/` — data analysis, visualization, and exploratory data analysis
- `Machine Learning/` — supervised learning exercises covering regression and classification, and unsupervised learning exercises covering clustering, dimensionality reduction, autoencoders, and association rules
- `NLP/` — natural language processing exercises covering tokenization, text preprocessing, spaCy-based NLP workflows, and language analysis

## Learning Journey

### 1. Python Fundamentals

Focus on:
- Variables and data types
- Operators and expressions
- Conditional statements
- Loops and control flow
- Input/output handling
- Basic problem solving

### 2. Data Structures

Focus on:
- Lists, tuples, dictionaries, and sets
- Stack, queue, linked list, tree, and graph concepts
- Efficient data organization and manipulation

### 3. Object-Oriented Programming

Focus on:
- Classes and objects
- Constructors and methods
- Encapsulation and abstraction
- Inheritance and polymorphism
- Structured program design

### 4. Data Analysis and Visualization

Focus on:
- NumPy arrays and vectorized operations
- Pandas data structures and analysis
- Data cleaning and transformation
- Data visualization with Seaborn and Matplotlib

### 5. Machine Learning (Supervised and Unsupervised Learning Completed)

Focus on:
- Supervised learning: linear and polynomial regression, logistic regression, train/test splits, and model evaluation
- Unsupervised learning: DBSCAN and Gaussian Mixture Model clustering, PCA, autoencoders, and frequent itemset/association-rule mining
- Practical machine learning workflows using NumPy, Pandas, and scikit-learn
- Reinforcement learning and self-supervised learning are additional topics for future study

### 6. Natural Language Processing (Completed)

Focus on:
- Text preprocessing and cleaning
- Tokenization and sentence analysis
- Stopword removal and normalization
- Named entity and part-of-speech basics
- Practical NLP workflows using spaCy
