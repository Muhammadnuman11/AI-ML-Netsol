# AI/ML Training at NETSOL Technologies Pakistan

This repository documents my learning journey through the AI/ML training program at NETSOL Technologies Pakistan. It contains practical exercises, Python scripts, notes, and project work covering the fundamentals of programming, data structures, machine learning, and data analysis.

The goal is to build strong hands-on experience in artificial intelligence and machine learning while learning in public and sharing continuous progress.

## Overview

- Duration: 3 Months
- Learning Mode: Practical + Theory
- Focus Areas: Python, Data Structures, OOP, NumPy, Pandas, Machine Learning, Data Visualization, and AI concepts
- Purpose: Strengthen foundational skills and prepare for real-world AI/ML development

## Repository Structure

This repository is organized by topic and learning module:

- `Python lec 01/` — introductory Python practice and basic coding exercises
- `Basic Python 04 - 05/` — core Python concepts including conditionals, loops, and logic-building programs
- `Data Structures in python 03/` — lists, tuples, sets, dictionaries, stacks, queues, linked lists, trees, and graphs
- `Linux lec 02/` — Linux fundamentals, file operations, commands, shell usage, and system basics
- `OOP in python 06 - 07/` — object-oriented programming concepts such as abstraction, encapsulation, inheritance, and polymorphism
- `NumPy and Pandas/` — numerical computing and data manipulation with NumPy and Pandas
- `Pandas and Seaborn/` — data analysis, visualization, and exploratory data analysis
- `Machine Learning/` — introduction to machine learning concepts and supervised/unsupervised learning foundations
